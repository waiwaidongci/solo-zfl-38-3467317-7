# 古船模型帆索校准

运行：

```bash
npm start
```

访问 `http://localhost:3038`。数据保存在 `data/model-rigging-calibration.json`（写入采用临时文件+改名，重启后数据仍在）。

测试：

```bash
npm test
```

## 角色（页面右上角切换）

- **计量员**：登记量具及有效期、调整有效期、停用量具（先影响预览，确认后生成复测批次）。
- **校准员**：为每根帆索录入测量值，只能选择「在用且未过期」的量具。
- **复核员**：对已测量的帆索登记复核结论（通过/不通过）。

每根帆索保留量具、测量值、操作人和复核记录。

## 量具停用与复测闭环

1. 计量员在量具台账点「停用」，先看到影响预览：未交付项目将**退回校准**（保留旧测量记录），已交付项目只**标风险**（不改历史；同一项目被多个停用量具影响时保留全部风险，可逐条查看并按量具/风险筛选）。
2. 确认后生成唯一复测批次：重复确认复用原批次不会重复建批；预览后量具信息有变化（过期版本）会被拒绝并要求重新预览；校验全部通过才一次性落库，失败不留半批数据。
3. 复测中项目被锁定，不能推进到待复核/已交付；校准员换用有效量具复测、复核员复核通过后自动解锁，批次全部复核完自动完成，流程恢复。
4. 批次完成后该闭环即关闭：没有新测量的重复复核会被拒绝，任务状态不再被改回；后续问题需重新测量，进入新的校准闭环。

## 并发与版本

- 修改量具有效期必须携带当前版本号（页面「改期」自动带上），缺失或过期版本返回 409 且不改数据。

## 页面

- 按状态、量具、风险（复测中/有风险/正常）、负责人筛选，支持关键词搜索。
- 复测批次卡片显示进度条与下一步（等待谁复测/复核哪一根）。
- 原建档、帆索任务、状态推进（校准→复核→交付）入口保持可用。
